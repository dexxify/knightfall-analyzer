# Knightfall Analyzer

Review your chess games on your own computer: Stockfish analyses every move, and a voiced AI
coach of your choosing explains what happened. No account, no subscription, no cloud.

Knightfall Analyzer is free software (GPL-3.0-or-later). It is an independent project and is **not
affiliated with Chess.com or Lichess**.

> Status: early (0.1). The core workflow works end to end; see [What is not done](#what-is-not-done).

## What it does

- **Import** games from a Chess.com or Lichess link, a player's archive, PGN files (drag and
  drop, multi-game) or pasted PGN.
- **Analyse locally with Stockfish**: the latest official release is downloaded and verified
  from inside the app. Full-game review in Quick, Standard or Deep presets; live analysis with
  several lines while you browse.
- **Classify every move** from engine output: Brilliant, Great, Best, Excellent, Good, Book,
  Inaccuracy, Mistake, Missed win, Blunder, Forced. Accuracy per player, key moments, an
  evaluation graph, and an evaluation bar.
- **Explore variations**: play any move on the board or click an engine line; it is analysed
  and kept clearly apart from the game.
- **Twenty coaches** with different personalities, from The Mentor to The Toxic Best Friend,
  plus a "create your own coach" editor. Personality changes the tone; the chess facts always
  come from Stockfish.
- **The coach speaks.** Explanations are generated by a local language model and spoken by a
  local voice engine, each coach with their own voice. Automatic move-by-move explanations,
  follow-up questions, pause / replay / skip / mute.
- **Everything has a button**: install, update, test and repair Stockfish; download and remove
  AI models and voice engines; back up, restore and export your data.
- **Private by design**: games, analysis and conversations stay in a local SQLite database.

## Installing

Download the installer for your system from the Releases page and run it. On first launch a
setup wizard detects your hardware and offers to install Stockfish, a recommended AI model and
a voice engine. You do not need Python, Node.js, LM Studio, Ollama or a terminal.

Large components are downloaded only when you press their button, and the app shows the size
first:

| Component | Size | Needed for |
|---|---|---|
| Stockfish | about 80 MB | All analysis |
| AI model (Qwen3.5 2B to 27B) | 1.3 to 16.7 GB | Coach explanations |
| Kokoro voice engine | 92 or 326 MB | Spoken explanations |

After that, everything works offline. Engine analysis works without an AI model; the coach
needs one.

Prefer your own model server? Settings → AI Coach also connects to **LM Studio**, **Ollama**,
any **OpenAI-compatible** endpoint and any **Anthropic-compatible** endpoint. A clear indicator
is shown whenever the provider is not on your computer.

## Building from source

Requirements: Node.js 22.12 or newer, npm.

```bash
npm install
```

```bash
npm run dev
```

```bash
npm test
```

```bash
npm run dist
```

- `npm run dev` starts the app with hot reload.
- `npm test` runs the unit tests. Set `STOCKFISH_PATH` to a Stockfish binary to include the
  tests that drive a real engine.
- `npm run dist` builds an installer into `release/` for the current platform.
- `node tests/e2e/setup.mjs <data-dir>` and the other scripts in `tests/e2e/` drive the built
  app (run `npm run build` first). They use the network and download real components.

## How move classification works

A move is graded by how much win probability it gave up compared with the engine's best move
(the logistic win-probability curve published by Lichess), not by raw centipawns, so a pawn
lost in an equal position counts for more than a pawn lost when already winning. Mate scores
are handled as certainties. "Brilliant" requires all of: the engine's first choice, real
material offered, the engine confirming it is sound, and the next-best move being clearly
worse. Thresholds are configurable in Settings → Engine. Accuracy uses Lichess's published
method. Details: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## What is not done

- **Expressive speech (Qwen3-TTS)** is designed for but not implemented; the shipped voice
  engine is Kokoro, which is natural and clear but does not shout or laugh.
  See [docs/TTS.md](docs/TTS.md).
- **GPU acceleration for the built-in AI model uses Vulkan** (and Metal on macOS). CUDA builds
  are not bundled because they need the CUDA runtime installed separately.
- **Opening Explorer** is not implemented; openings are identified by name only.
- **Installers are unsigned**, and only the Windows build has been run. macOS and Linux
  packaging is configured but untested.
- **Auto-update** of the application itself is not implemented.
- **User-supplied piece sets** are not loadable yet; three sets and six boards are built in.
- **Speech is English only**; the coach's text can be in any language your model writes.
