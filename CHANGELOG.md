# Changelog

## 0.1.0 — unreleased

First working version.

- Import from Chess.com (Published-Data API), Lichess (API), PGN files and pasted PGN.
- In-app Stockfish install, update, test, repair; UCI engine layer; Quick/Standard/Deep review.
- Engine-based move classification, accuracy, key moments, evaluation bar and graph.
- Variation exploration with live analysis.
- Twenty coach profiles and a custom coach editor with import/export.
- Built-in local AI runtime (llama.cpp) with a verified model catalogue and hardware-based
  recommendations; LM Studio, Ollama, OpenAI-compatible and Anthropic-compatible providers.
- Local speech with Kokoro; sentence-level streaming; speech queue with cancel on navigation.
- First-run setup wizard; backup, restore, export, repair.

Known gaps are listed in the README under "What is not done".
